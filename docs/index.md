# AudioMark Library

AudioMark Library объединяет мобильную библиотеку аудиокниг и централизованный сервис комментариев. Книга может состоять из нескольких аудиофайлов. Сервер индексирует файлы, вычисляет контрольные суммы MD5 и предоставляет каталог через HTTP API.

## Возможности

- просмотр каталога и поиск без повторного обращения к серверу;
- воспроизведение многосоставных аудиокниг;
- автоматическое продолжение с сохраненной позиции;
- перенос завершенных книг в категорию «Прослушано»;
- комментарии и отметки «Нравится» на текущей позиции;
- переход к позиции любого комментария;
- работа в вертикальной и горизонтальной ориентации.
