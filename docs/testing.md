# Проверка функций

Автоматические тесты проверяют:

1. вычисление MD5 для одинаковых и различных данных;
2. экранирование строк при формировании JSON;
3. разбор строкового и числового поля JSON;
4. фильтрацию каталога без учета регистра;
5. вычисление признака завершения книги;
6. форматирование временной метки;
7. безопасное имя каталога книги;
8. определение поддерживаемых аудиоформатов.

После автоматических тестов выполняется ручная проверка: запуск контейнера, открытие каталога, воспроизведение, закрытие и повторное открытие книги, добавление комментария, переход по метке и смена ориентации экрана.
