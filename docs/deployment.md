# Развертывание

## Требования

- Docker Engine 24 или новее;
- Docker Compose v2;
- свободный порт 8080;
- Android Studio для сборки мобильного клиента.

## Подготовка каталога

В `server/data/audio` создайте по папке на каждую книгу. Аудиофайлы внутри папки сортируются по имени. Поддерживаются файлы с расширениями `.mp3`, `.m4a`, `.aac`, `.ogg` и `.wav`.

В папке книги можно разместить `book.properties`:

```properties
title=Название книги
authors=Имя автора
description=Краткое описание
```

Обложка должна называться `cover.png`, `cover.jpg` или `cover.jpeg`.

## Запуск

Из корневого каталога выполните:

```bash
docker compose up --build -d
```

Состояние сервиса проверяется запросом:

```bash
curl http://localhost:8080/api/health
```

Индексирование выполняется при каждом запуске контейнера. Повторно найденные файлы сопоставляются по MD5 и не дублируются.

## Подключение мобильного клиента

Эмулятор Android обращается к компьютеру по адресу `10.0.2.2`, поэтому стандартный базовый URL равен `http://10.0.2.2:8080`. Для физического устройства укажите локальный IP-адрес компьютера в `ApiClient.java`. Устройство и сервер должны находиться в одной сети, а входящие соединения на порт 8080 должны быть разрешены.
